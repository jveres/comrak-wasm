# Clean-code and performance audit

This audit records the repository state on 2026-09-24, after a dependency
refresh. It follows the [2026-07-14 audit](audit-2026-07-14.md). Measurements
use release Wasm on an Apple M2 with Node.js 24.

## Outcome

The round fixes every High and Medium finding from three parallel audits
(Rust clean code, JavaScript and TypeScript clean code, performance) and three
verification rounds over the fixes. The largest changes follow.

- The global allocator was quadratic. Large renders now scale linearly and are
  up to 21 times faster.
- Source-map attribute splicing was quadratic and is now one linear pass.
- `mdToAst` could overflow the Wasm stack and break the module for later calls.
  It now has the same nesting guard as text and ANSI output.
- `healMarkdown` now follows Markdown context: code spans, list bullets, URLs,
  and containers. It no longer deletes text after `a<b` or closes delimiters
  inside code.

## Dependencies

- Biome 2.5.14, Vitest and coverage 5.0.1, `@types/node` 26.6.2,
  fast-check 4.10.2, KaTeX 0.18.7, Vite 8.3.0.
- `wasm-bindgen` 0.2.128 and `js-sys` 0.3.105, with the matching

- Comrak stays at 0.55.0, its latest release.
- `lol_alloc` is removed.

## Measurements

The table compares `pnpm run bench` before and after the round, in
microseconds per operation.

| Measure | Before | After | Change |
| --- | ---: | ---: | ---: |
| `mdToHtml`, 8,000 paragraphs | 325,720 | 16,057 | 20x faster |
| `mdToHtmlBlocks` source map, 4,000 code and math spans | 702,162 | 33,707 | 21x faster |
| `mdToText`, table 1,000 by 10 | 73,452 | 4,677 | 15.7x faster |
| `mdToText`, skewed table | 1,675 | 796 | 2.1x faster |
| `mdToHtml`, 1,000 headings | 1,217 | 443 | 2.7x faster |
| `mdToHtml`, mixed document | 1,197 | 602 | 2.0x faster |
| `mdToText`, mixed document | 1,111 | 535 | 2.1x faster |
| Heal, 256 KiB bracket-heavy input | 10,173 | 7,582 | 25% faster |
| Heal, 256 KiB single paragraph | 1,016 | 1,099 | 8% slower |
| Tiny renders | 1.15 | 1.19 | within noise |
| Wasm artifact | 1,003,654 B | 1,026,978 B | 2.3% larger |

Before the allocator change, `mdToHtml` time grew about four times with each
doubling of the input. It now doubles, as expected. The default allocator adds
about 7 KB to the artifact and three Wasm pages to the first-run high-water
mark. The single-paragraph healer case pays for the structural scan that makes
the healer context-aware.

## Fixed findings

### Performance

- **High — allocator.** `lol_alloc::FreeListAllocator` walks its free list on
  every allocation and free. The default Rust allocator replaces it.
- **High — source-map splicing.** `mdToHtmlBlocks` inserted each source-map
  attribute with `String::insert_str` and then shifted every block end. It now
  sorts the insertions and rebuilds the HTML in one pass.
- **Medium — character columns.** With `parse.sourceposChars`, streaming and
  source maps rescanned the line for every node. One shared `Columns` helper
  now builds its index once per source, and uses byte columns for ASCII. The
  two copies also disagreed about clamping past the end of a line; both now
  clamp.
- **Low — source-map memory.** `SourceMap` borrows the source instead of
  copying it, and skips its UTF-16 index for ASCII input.

### Healing

- **High — text loss after `<`.** A `<` followed by a letter removed the rest of
  the input when no `>` followed, even inside code spans. `if a<b then c`
  became `if a`. A partial tag must now follow a non-word character, be outside
  code, and match the partial-tag grammar.
- **Medium — delimiters inside code.** ``use `**kwargs` `` gained a stray
  `**`, and `[`, `](`, `$$`, and `~~` inside code spans were healed too.
  One structural scan now finds fenced code, code spans, list bullets,
  thematic breaks, link destinations, and bare URLs. Every healer skips those
  regions.
- **Medium — list bullets.** `* item` became `* item*`, and `***` or `___`
  thematic breaks were treated as emphasis.
- **Medium — fences in containers.** Fences inside list items and blockquotes
  were not detected. The closer is now indented and quoted to match its
  container, and an open fence ends when its container ends.
- **Medium — setext healing inside open fences.** The healer escaped a `-`
  line inside an unclosed fence.
- **Low — paragraph detection.** Whitespace-only lines, `\r\n` blank lines,
  and empty blockquote lines now separate paragraphs.
- **Low — bare URLs.** `https://x.com/_private` no longer gains a closing `_`.
- **Low — trailing newlines.** Closers go before trailing newlines, so
  `a **b\n` heals to `a **b**\n`. Streaming, which must only append, waits
  for the next chunk instead of adding a closer that would start an empty list
  item.

The last verification round cut every repository document at every character
offset (about 52,800 prefixes) and compared healing and streaming against the
previous release. HEAD damaged the text after `` `\e[` `` and after
`` `a<b` ``; the new healer does not. In a sanitized copy without those
constructs, the differences were improvements or neutral, except for one case:
a lone opening backtick in open emphasis stopped emphasis from closing. That
case is fixed.

Idempotence holds for one million random inputs built from Markdown
fragments, including containers, fences, and URLs. A seeded property test with
the same fragments runs in the Vitest suite.

### Rendering

- **High — `mdToAst` stack overflow.** Deep nesting now returns a `RangeError`
  before recursion, and the module stays usable.
- **Medium — alert title.** Text output printed `[Alert]` instead of the alert
  type, such as `[Note]`.
- **Medium — ANSI with an empty `reset`.** The alert badge and OSC 8 link
  closers no longer emit unpaired escapes.
- **Medium — partial ANSI themes.** A partial theme dropped the default table
  shadow; missing fields now come from the defaults.
- **Medium — quote borders.** Headings, thematic breaks, and code blocks inside
  blockquotes keep the `│` border in text and ANSI output.
- **Medium — `mdToInlineHtml` with `render.sourcepos`.** It no longer rejects a
  paragraph whose opening tag carries `data-sourcepos`.
- **Medium — `ansiToHtml` escapes.** Character-set escapes such as `ESC ( B`,
  other two-byte escapes, and private CSI parameters are dropped instead of
  leaking `ESC` into the HTML.

### JavaScript and TypeScript

- **Medium — `CodefenceRenderer`.** The exported class is now accepted in
  renderer maps. `index.js` passes clones, so the caller's handle stays usable.
  Passing a `PreparedCodefenceRenderers` handle to a top-level function gives a
  targeted `TypeError`.
- **Medium — URL rewriter failures.** Rewriters fail open: a throw or a
  non-string result emits the original URL. README and the typings now say so.
- **Medium — handle leak test.** The plugin memory test now frees its handles
  and also checks the externref table, which linear memory cannot show.
- **Medium — typings.** `mdToHtmlBlocks`, `mdToStreamingHtmlBlocks`, and
  `mdToAnsi` accept `null` options or themes, as the runtime does.
- **Medium — playground ANSI parser.** The playground renders ANSI through the
  exported `ansiToHtml` instead of its own 180-line parser.
- **Low.** README explains that `free()` and `using` must not be combined, the
  Shiki example gives the right command, and CLI tests resolve paths with
  `fileURLToPath`.

## Follow-up fixes

- **v0.5.2 — tabs in list fences.** Indentation and the gap after a list
  marker use four-column tab stops, so a tab-indented line stays inside its
  list item's fence and the closer gets the right indent.
- **Backslashes in code spans.** Only an opener's first backtick can be
  escaped; inside a span a backslash is literal. ``Use `C:\` drive`` no longer
  gains a stray closing backtick.

## Remaining findings

- **Low — repeated structural scans.** Each inline healer re-analyzes the
  text, because the healer before it may have appended a closer. The work is
  linear, but the constant factor grows with the number of healers. Streaming
  and link healing share one scan.
- **Low — rare healing shapes.** `***bold italic*` heals with a stray `**`,
  `_` inside unclosed `$$` math counts as emphasis, and a trailing line of
  spaces keeps emphasis open. None is worse than the previous release.
- **Resolved — quoted fence idempotence.** A removed marker left a trailing
  space that hid a quoted fence's last line, so the fence closed only on a
  second pass. The trailing space is now stripped before the fence healer
  runs.
- **Low — idempotence corner cases.** Rare combinations of a removed bracket
  that exposes a link destination can heal differently on a second pass, as
  in `"x][(\n$$\n<b>`\n-"`. Healers never run on their own output in normal
  use.
- **Upstream — character columns.** Comrak's own parser is quadratic on one
  very long non-ASCII line with `sourceposChars`.
- **Medium, carried over — batched plugins.** This still needs a separate API
  design.
